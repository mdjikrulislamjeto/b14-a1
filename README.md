# 🚀 DEVCONF – Developer Conference

A modern and responsive developer conference landing page built as a front-end web development assignment. DEVCONF presents a fictional 2026 developer conference featuring industry speakers, conference plans, AI innovation zones, and registration options.

## 🌐 Live Demo

🔗 **[View Live Website](https://jikrulislamjeto.github.io/b14-a1/)**

## 📌 About the Project

**DEVCONF** is a developer conference website designed to provide information about a three-day technology conference.

The website includes conference highlights, featured speakers, pricing plans, and an AI Innovation Hub covering modern technologies such as Artificial Intelligence, Cloud Computing, Cybersecurity, and Data Analytics.

## ✨ Features

* 🎤 Featured Speakers section
* 📅 Conference Schedule navigation
* 🛤️ Technology Tracks
* 📍 Venue section
* 📝 Conference Blog
* 🎟️ Registration options
* 💳 Multiple pricing plans

  * Standard
  * Pro
  * Team
* 🤖 AI Innovation Hub
* ☁️ Cloud technology showcase
* 🔒 Cybersecurity section
* 📊 Data Analytics section
* 📱 Responsive and modern UI
* 🖼️ Custom visual assets and illustrations

## 🛠️ Technologies Used

* **HTML5** – Website structure and semantic content
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Interactive functionality
* **Git & GitHub** – Version control
* **GitHub Pages** – Website deployment

```bash

```

### 2. Open the project

Navigate to the project directory:

```bash
cd b14-a1
```

### 3. Run the website

Open `index.html` in any modern web browser.

No additional installation or dependencies are required.
